## 1. 本階段的多人持有假設

暫以「每位玩家各自持有 3 個常駐槽與 2 個消耗品槽」作為審查假設；不允許玩家自由交易。團隊協作由明確標示的共享獎池道具提供。這是為了讓道具歸屬、觸發順序和收益記帳可判定，尚未視為最終核准的遊戲規格。

## 2. 全域結算規則修訂建議

現有文件的「同一事件每件道具最多觸發一次」與「同一事件不能重複觸發獲得籌碼效果」過於籠統，可能意外殺死合法連鎖構築。建議改為以下分層規則：

1. 每次賭局建立唯一的 `round_id`，每次原始結果建立唯一的 `event_id`。
2. 道具效果分為「原始賭局事件觸發」與「道具產生的衍生事件」；衍生事件不會自動被所有道具監聽。
3. 每件道具明確列出可監聽的事件類型、每局／每 run 次數、是否能被衍生事件觸發，以及效果目標。
4. 預設禁止道具遞迴觸發自身；但不同道具之間的連鎖可被明確允許。若構築有意設計成循環，必須把啟動條件、消耗、終止條件與每次循環的資源變化寫清楚。
5. 同一次原始損失可讓多件道具依序「提出保護」，但預設只允許一件改寫該筆損失；玩家選擇或固定優先序須在知道保護後結果前確定。其他道具若提供詛咒、籌碼或不同資源，必須明確說明是否仍觸發。
6. 所有金額先以整數籌碼記帳；比例運算的向下取整時機固定在每項效果內，不能由實作自行決定。
7. run 結束時，未清債務、延遲獎勵、公共金庫和未結算觸發必須有明確的結清／失效規則；不能靠重開 run 把應付代價洗掉。
8. 不把「有上限」當成預設平衡手段。上限必須有遊戲節奏、多人互動或結算可判定性的理由；若上限只是防止玩家太強，應先檢查能否保留強度、改用可理解的成本或兌現窗口。

## 4. 目前最值得追查的資源循環

這些是待測假設，不是已證實漏洞：

### A. 破碎王冠 + 低成本可爆掉賭局
- 路徑：選最低下注額 → 刻意選擇高機率爆掉 → +60 → 重複直到裂痕限制或 run 結束。
- 必須查明：最低下注額、是否可選擇保證爆掉的玩法、道具取得成本、裂痕對後續下注的真實影響、能否用換裝／重開重置裂痕。
- 判斷原則：如果玩家真的承擔了高風險與構築代價，可能是合理玩法；如果存在低成本保證爆掉且收益遠大於成本的無風險循環，則修正這條路徑，不先刪除王冠。

### B. 罪債天平 + 沉重利息 + 延後結算
- 路徑：取得 80 → 延後兩場償還 120 → 利息持續增加 → 透過新債務／重開／run 結束逃避付款。
- 必須查明：罪債天平是否允許已有債務時使用、債務是否可疊加、run 終局扣款、利息何時停止。
- 判斷原則：允許危險的借貸構築，但不能讓已到期債務因重開而消失。

### C. 退路籌碼 + 逆命印章 + 破產保險箱
- 路徑：同一損失被三件道具各自改寫或保護，將災難結果變成幾乎零損失。
- 必須查明：哪件先觸發、玩家是否能看見結果後再挑保護、破產標記是否在其他保護後才計算。
- 判斷原則：可以允許罕見的強力保護構築；但每筆損失必須有明確、可重現的結算結果，不能由實作順序碰運氣。

### D. 黑曜石籌碼 + 逆命印章 + 詛咒封蠟
- 路徑：把損失轉成詛咒、詛咒換籌碼、再移除詛咒。
- 必須查明：封蠟能否移除逆命印章剛產生的詛咒、黑曜石是否已領 40、移除後能否再次把同一事件當成新詛咒。
- 判斷原則：若玩家消耗了道具與 20 籌碼完成一個強力轉換，可以是合法協同；禁止同一個詛咒事件被重複支付獎勵。

### E. 信任徽章 + 背叛者的印記
- 路徑：固定玩家協議合作／背叛，取得合作獎金與怨氣兌換。
- 必須查明：怨氣能否跨 run、兌換成本與道具價值、合作／背叛各自承擔的籌碼風險。
- 判斷原則：玩家社交策略與預先協議不必被消滅；只需防止系統把同一個 Pot Split 事件重複記帳或憑空產生多份獎勵。

### F. 緊急提款單 + run 尾端商店缺席
- 路徑：在最後一次可能使用消耗品時獲得 +50，且不再遇到商店承擔 25% 漲價。
- 判斷原則：這是明確的時機差異，可能是有趣的尾端選擇，不自動視為漏洞。只有當它令其他所有消耗品完全無價值時，才比較整體選項。

## 5. 靜態規則檢查清單

在開始數值模擬前，先逐項確認：

- [ ] 每件道具都指定事件類型，而不是只用模糊的「失敗」「返還」「爆掉」。
- [ ] 每個事件只產生一個原始結算紀錄，衍生效果不能重複執行原始賭局結算。
- [ ] 所有一次性／每場／每 run 次數都由唯一 ID 記帳。
- [ ] 所有保護效果的先後順序與互斥規則明確。
- [ ] 每個百分比都有基數、取整方式與套用時點。
- [ ] 所有延遲債務都定義到期場次、提前終局與重開處理。
- [ ] 公共金庫每筆存入、返還、增幅與損失都有明確資金來源。
- [ ] 道具出售、重抽、替換和消耗不會重複發放同一筆獎勵。
- [ ] 強力循環被分類為「合法極端構築」「有限但高回報循環」「疑似無成本漏洞」之一，不能只標成「太強」。
- [ ] 每項修正都保留原本想提供的玩法，除非有證據顯示核心規則無法成立。

## 6. 本次結論

1. 24 件道具中，目前沒有足夠證據能直接判定哪件必須移除；這一輪是規則審查，不是數值平衡裁決。

3. 「破碎王冠」與「罪債天平」應視為高風險構築候選，先找實際路徑與兌現成本；不以強度高作為刪除理由。
